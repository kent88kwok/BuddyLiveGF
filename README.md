BuddyLiveGF 为 macOS 版 WorkBuddy 加入两套动态角色主题，并根据 WorkBuddy 的外观设置自动匹配：浅色外观使用暖白女友，深色外观使用深色赛博女友。

## 功能

- 暖白、深色两套动态角色主题
- 自动跟随 WorkBuddy 浅色／深色外观
- 角落与沉浸两种角色布局
- WorkBuddy 页面内即时切换布局
- 新建任务、助理和任务详情页面统一适配
- 不修改 `WorkBuddy.app` 应用包
- 本地回环连接，不提供网络服务

## 下载与安装

1. 打开右侧 [Releases](../../releases) 页面。
2. 下载最新版 `BuddyLiveGF-*-macOS.zip`。
3. 解压后打开 `BuddyLiveGF.app`。
4. 从 macOS 菜单栏选择“安装并应用 Live 皮肤”。

首次打开如遇到 macOS 安全提示，可在 Finder 中按住 Control 点击应用并选择“打开”。当前公开构建使用 ad-hoc 签名，尚未进行 Apple 公证。

## 系统要求

- macOS
- 官方 WorkBuddy 桌面版
- Node.js 20 或更高版本
